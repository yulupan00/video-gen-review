# Soccer play studies

Three short studies on soccer plays, hosted with GitHub Pages; the tabs at the top of each page switch between them.

1. **Better play** (`index.html`): one moment from a match and two short clips of how the play could continue; pick the better play, or no preference.
2. **Realism** (`realism/`): one clip at a time; could these movements plausibly occur in a competitive game?
3. **Shot value** (`value/`): two shots, each stopped at the release; which is more likely to score?

The earlier four-clip version of the first study is kept under `v1/`.
